11번째 프로젝트 'convertfile'의 기획을 축하드립니다! 메인 화면의 자연어 기반 라우팅부터 다양한 포맷의 파일 변환, PDF 편집, 그리고 플로팅 계산기까지 실무에 매우 유용한 기능들로 꽉 찬 훌륭한 기획입니다.

특히 모바일 가로/세로 모드의 UI 구조를 분리하여 반응형 성능을 끌어올리려는 접근은 프론트엔드 최적화 관점에서 매우 탁월한 선택입니다.

성공적인 프로젝트 구체화를 위해 **최적의 API 세팅 조언**과 **실무 활용도를 높일 추가 기능 아이디어**를 제안해 드립니다.

---

## 1. 핵심 기능 구현을 위한 최적의 API 및 라이브러리 추천

파일 변환(특히 HWP 포함)과 자연어 처리, 계산기 기능 등을 완벽하게 구현하기 위해 다음과 같은 기술 스택과 API를 조합하는 것을 권장합니다.

* **메인 페이지 (자연어 라우팅 및 LLM 검색)**
* **Gemini API (기본 탑재):** 입력된 텍스트/음성의 의도를 파악(Intent Classification)하여 특정 메뉴로 라우팅하거나, 일반 검색 결과를 반환하는 데 사용합니다.
* **음성 인식(STT):** Google Cloud Speech-to-Text API를 활용하면 한국어 음성 인식률을 극대화할 수 있습니다.


* **파일 변환 (2~8번째 메뉴)**
* **ConvertAPI 또는 Cloudmersive API:** PDF, Word, PPT, Excel, TXT 간의 상호 변환을 지원하는 가장 강력하고 안정적인 글로벌 API입니다.
* **HWP (아래아한글) 변환 이슈:** HWP는 한국 특유의 포맷이므로 글로벌 API에서는 지원하지 않는 경우가 많습니다. HWP 변환을 위해서는 **사이냅소프트(Synapsoft) 문서 변환 API**나 **폴라리스 오피스 API** 도입을 검토해야 합니다. (비용 문제 시, HWP를 PDF로 변환하는 오픈소스 백엔드 서버를 별도로 구축하는 것도 방법입니다.)


* **PDF 합치기 및 편집 (9~10번째 메뉴)**
* 이 기능은 굳이 외부 API를 써서 서버 비용을 낼 필요가 없습니다. Flutter의 `syncfusion_flutter_pdf` 또는 `pdf` 패키지를 사용하면 **클라이언트(브라우저/앱) 단에서 직접** PDF 페이지 재배열, 삭제, 병합, 추출을 매우 빠르고 무료로 처리할 수 있습니다.


* **전체화면 계산기 (환율 계산)**
* **환율 API:** 한국수출입은행 환율 API(무료, 국내 기준 정확함) 또는 ExchangeRate-API를 연동하여 실시간 환율 정보를 제공할 수 있습니다.

## 2. 'convertfile'에 날개를 달아줄 비즈니스 추가 기능 제안

단순한 변환을 넘어, 실제 업무(기획, 마케팅, 영업 등)에서 "이 기능 때문에 이 앱을 쓴다"라고 느낄 만한 아이디어입니다.

* **AI 기반 문서 요약 (Gemini 활용)**
* 변환된 파일(예: 수십 장의 PDF나 PPT)을 다운로드하기 전에, 메인 페이지의 Gemini를 활용해 **"이 문서의 핵심 요약 3줄 보기"** 버튼을 제공합니다. 문서를 열어보지 않고도 내용을 파악할 수 있어 업무 효율이 급상승합니다.


* **OCR (이미지 안의 텍스트 추출)**
* 스캔된 PDF나 이미지 파일을 업로드하면, Gemini 1.5 Pro의 강력한 Vision 기능을 이용해 수정 가능한 텍스트(.txt 또는 .md)로 완벽하게 변환해 주는 기능을 추가합니다.


* **변환 히스토리 및 1-Click 공유**
* Firebase Storage와 연동하여 최근 7일간 내가 변환한 파일들의 목록(히스토리)을 마이페이지 쪽에 제공합니다.
* 파일을 직접 다운로드하는 대신 '비밀번호가 걸린 공유 링크(URL)'를 생성해 거래처나 팀원에게 바로 카카오톡/이메일로 보낼 수 있게 합니다.


* **일괄 변환 (Batch Processing)**
* 10개의 워드 파일을 한 번에 업로드하여 모두 PDF로 바꾸는 다중 파일 처리 기능을 넣으면 실무자들의 반복 작업 시간을 크게 줄여줍니다.

## 3. 프로젝트 준비 체크리스트

효율적인 개발을 위해 우선적으로 확보하고 테스트해야 할 API와 키값들을 체크리스트로 정리했습니다.

### 1. 프로젝트 개요

* **프로젝트명:** ConvertFile (11번째 업무용 프로젝트)
* **목적:** 다국어 자연어 처리 기반의 지능형 파일 변환 및 PDF 편집, 실무 보조 도구(계산기 등)를 통합하여 업무 생산성을 극대화하는 반응형 웹/앱 서비스 구축
* **주요 기술 스택:**
* **Frontend:** Flutter (웹/모바일 크로스 플랫폼 지원)
* **Backend / DB:** Firebase (인증, DB, Storage) & Google Cloud (보조 인프라)
* **AI Core:** Gemini API (자연어 인식, 의도 분석, 텍스트 요약/OCR)
* **Deployment:** GitHub Repository -> Vercel 또는 Netlify 배포



### 2. 핵심 메뉴 및 기능 정의

**[메뉴 1] 메인 페이지 (AI 라우팅 및 검색 센터)**

* **입력 방식:** 텍스트 입력, 음성 인식(STT), 파일 업로드
* **AI 처리 엔진 (Gemini API 탑재):** 입력된 자연어/파일의 의도를 분석하여 적합한 변환 및 편집 메뉴(2~10번)로 자동 라우팅.
* **Fallback 로직:** 매칭되는 메뉴가 없을 경우, 일반적인 LLM 기능을 수행하여 정보를 검색하고 답변을 출력.

**[메뉴 2~8] 지능형 파일 변환 (Format Conversion)**
업로드한 파일을 타겟 포맷으로 변환하는 핵심 기능으로, 각 메뉴별 상호 변환을 지원.

* **지원되는 원본 파일:** .md, .pdf, .doc, .docx, .ppt, .pptx, .xls, .xlsx, .hwp, .hwpx, .hwt, .txt
* **각 메뉴별 타겟 포맷:**
* [메뉴 2] Markdown (.md)으로 변환
* [메뉴 3] PDF (.pdf)로 변환
* [메뉴 4] Word (.docx)로 변환
* [메뉴 5] PowerPoint (.pptx)로 변환
* [메뉴 6] Excel (.xlsx)로 변환
* [메뉴 7] 아래아한글 (.hwp, .hwpx, .hwt)로 변환
* [메뉴 8] 메모장 (.txt)으로 변환



**[메뉴 9~10] PDF 유틸리티**

* **[메뉴 9] PDF 합치기:** 다수의 PDF를 위에서 아래로 순차 업로드. 마우스 드래그 앤 드롭을 통한 순서 변경 지원. 기본 5개 슬롯 제공 및 풀다운 버튼으로 5개씩 확장(최대 20개).
* **[메뉴 10] PDF 편집:** 업로드한 PDF를 페이지 단위로 분할하여 보여주는 UX. 페이지 이동, 체크박스를 통한 특정 페이지 삭제, 선택된 페이지만 병합하여 출력(저장)하는 기능.

### 3. 공통 UX 요소 및 편의 기능

* **상시 노출 유틸리티 (로그인 후):**
* **로그아웃 버튼:** 모든 화면에 고정 노출.
* **마이페이지 버튼:** 클릭 시 내 정보 화면으로 이동 (ID 확인, 비밀번호 수정, 회원 탈퇴 기능 포함).
* **플로팅 계산기 (Pop-Up Calculator):**
* 화면 좌측 상단에 기본형 계산기 팝업으로 항시 띄움 (마우스로 잡고 자유롭게 이동 가능).
* **'Off' 버튼:** 팝업 닫기 기능.
* **'전체화면' 버튼:** [메뉴 11]에 해당하는 공학용/환율 계산이 가능한 확장형 전체 화면 계산기로 전환.





### 4. 고도화된 부가 기능 (추가 제안 반영)

* **문서 AI 요약 및 텍스트 추출:** 변환된 파일이나 매일 읽는 일본/영어 뉴스 원문 스크립트 파일을 다운로드하기 전에 Gemini API를 통해 핵심 내용을 요약하거나, 파일 내의 텍스트(장면 시나리오 등)를 바로 추출할 수 있는 프리뷰 제공.
* **일괄 변환 (Batch Processing):** 업무 효율을 위해 다수의 파일을 한 번에 업로드하여 동일한 포맷으로 변환하는 기능 지원.
* **히스토리 기반 간편 공유:** Firebase Storage에 변환 파일을 임시 저장하고, 보안 URL로 팀원과 빠르게 공유하는 기능.

### 5. 반응형 UI/UX 아키텍처 전략

빠르고 정확한 화면 렌더링을 위해 플랫폼별, 방향별 뷰(View) 구조를 완전히 분리하여 설계.

* **데스크톱(웹):** 좌측 사이드바(Sidebar) 영역과 메인 탭(Tab) 메뉴 디자인을 적용하여 넓은 화면에서의 다중 작업 효율성 확보.
* **모바일 (세로/가로 완전 분리형):**
* **가로 모드 (Landscape):** 좌측 미니 네비게이션 레일과 메인 작업 공간으로 분할.
* **세로 모드 (Portrait):** 하단 바(Bottom Navigation) 또는 햄버거 메뉴를 적용.
* **구조적 특징:** Media Query로 CSS만 변경하는 것이 아니라, Flutter 내에서 모바일 가로와 세로의 Widget Tree 자체를 분리(LayoutBuilder 활용)하여 빠르고 쾌적한 반응형 렌더링 구현.



### 6. 외부 API 연동 및 시스템 세팅 계획

* **AI 및 음성 인식:** 구글 Gemini API (텍스트/자연어 처리), Google Cloud STT API (음성 인식).
* **파일 변환 엔진:** Cloudmersive API 또는 ConvertAPI (글로벌 표준 파일 처리). 아래아한글(HWP) 처리의 경우 사이냅소프트 등 국내 특화 변환 API 병행 연동 검토.
* **클라이언트 PDF 처리:** `syncfusion_flutter_pdf` 패키지를 도입하여 서버 부하 없이 사용자의 기기 메모리상에서 PDF 병합 및 편집(페이지 삭제 등)을 즉각적으로 처리.
* **환율 데이터:** 한국수출입은행 등 공공 API 연동을 통한 실시간 환율 계산기 기능 구현.
